## 5. 调用的服务端接口

**两个服务端，别搞混：**

### ① 心履自己的服务端（`https://xin-lv.com`，Django）

| 用途 | 端点 | 认证 |
|---|---|---|
| 探活 | `GET /api/v1/ping/` | 免 |
| 注册 / 登录 / 注销 | `POST /api/v1/register/`、`/login/`、`/logout/` | Bearer |
| 拉取 / 推送心情记录 | `GET /api/v1/sync/pull/?since=`、`POST /api/v1/sync/push/` | Bearer |
| **长轮询** | `GET /api/v1/sync/watch/?since=` | Bearer |
| 内容目录 / 推荐 / AI 树洞 / 资料 | `/api/v1/catalog/`、`/recommend/`、`/chat/*`、`/profile/` | Bearer |
| 小游戏参数 | `GET /api/game-config/`（注意**没有** `/v1/`） | 免 |

认证是 `Authorization: Bearer <ApiToken>`。权威文档：`D:\moodsite\web\docs\心履API文档.md`。

### ② phix 服务端（`https://phix.ing`，Django）

统一账号、跨站免密登录、以及**应用内更新检查**：
`GET /api/v1/update/check?product=xinlv&platform=android`。

权威文档：`D:\phix\server\docs\协议规范.md`、`D:\phix\server\docs\同步实时化.md`。

### 长轮询最容易写错的一条

`changed=false` 有**两种含义相反**的情况，HTTP 层长得一模一样：

- **没有** `retry_after` → 正常挂满 25 秒超时 → **立刻**再挂（长轮询接力）；
- **有** `retry_after` → 服务端同时挂起的名额满了 → **必须先等**再挂。

把前者当后者会丢延迟，把后者当前者会**热循环打服务器**。
另外**读超时必须大于服务端的 25 秒挂起**（现在给 35 秒）。

### 安卓特有的一条

长轮询**只在前台跑**（`onStart` 起、`onStop` 停）。这是刻意的：安卓会杀掉后台进程里
挂着的长连接，留着既白耗电又白耗流量。回前台时由 `onStart` 补跑一轮完整同步兜住。

## 6. 本地数据与账号

- 账号与设置：`SharedPreferences("moodtree")`，键名与电脑版对齐
  （`serverBase` / `token` / `username` / `guestMode` / `themeId` / `accent` / `device`）。
- 业务数据：Room 数据库（`AppDatabase`），`MoodDao` 管心情记录、`CatalogDao` 管内容目录、
  `KvDao` 存零散键值（长轮询光标也在这）。
- **不要展示服务器地址这类技术细节**：用户明确要求过客户端不给用户看服务器地址、
  密钥、同步游标这些内部信息。
- 登出时要停掉长轮询环路，别拿着已失效的令牌继续请求。

## 7. 开发思路与约定

- **注释和提交信息用中文**，写**为什么**。
- **网络调用一律走 `Bg.run`**，绝不在主线程上做 I/O
  （否则要么 `NetworkOnMainThreadException`、要么卡界面）。
- **异步回调里先检查 Fragment 是否还挂着**（`isAdded()` / Activity 是否
  `isFinishing()` / `isDestroyed()`），再碰视图或弹对话框 —— 这是安卓最常见的崩溃来源。
- 更新检查要**三态**：`UP_TO_DATE` / `NEW_VERSION` / `FAILED`，
  **失败绝不能显示成「已是最新版本」**。三态映射做成纯函数（`UpdateReport`）便于单测。
- 打开外链用 `ACTION_VIEW` intent，并**包 try/catch**：没有能处理的应用时只提示、不崩。
  邮箱用 `mailto:`。
- 测试风格：纯逻辑单独测，网络用可注入的桩，不碰真网络。
- 版本号只有 `app/build.gradle` 一处来源（`PackageInfo` 读回来）。

## 8. 已知的坑与禁忌

1. **`versionCode` 与 `versionName` 必须一起加**，只加 `versionName` 装不上（覆盖安装会失败）。
2. **不要把网络调用放到主线程**，也不要在回调里直接碰可能已销毁的视图。
3. **「关于软件」的"检查失败"不能当"已是最新版本"**。
4. **`keystore.properties` 不进版本控制**，换机器要单独拷，否则出不了 release 包。
5. **长轮询只在前后台之间切换**：`onStop` 会停掉环路，这是设计不是 bug；
   回前台靠 `onStart` 的整轮同步兜住。
6. 老服务端没有 `/sync/watch/` 会返回 404 —— 要**安静降级**到定时同步，不要报错给用户。
7. 本机没有模拟器/真机，界面改动**没法自动验证**，别声称"测过了界面"。
8. 写 PowerShell 脚本要**带 UTF-8 BOM**。

## 9. 还没做的 / 建议下一步

- 界面没有自动化测试；如果要做，考虑 Robolectric 或接一台常驻真机。
- 后台同步目前完全没有（只有前台长轮询 + 周期同步）—— 如果要做，
  正确做法是 FCM 或 WorkManager，**不是**在后台挂长连接。
- 长轮询光标存在 `KvDao` 里，跨启动会恢复；如果发现恢复后行为异常，先查这里。
